# @omniterm/vscode-launch

Optional OmniTerm plugin that discovers `.vscode/launch.json` (`version >= 0.2.0`) across a pane's project folder and subfolders, exposes a header Launch dropdown for running one or multiple launches/compounds simultaneously, supports Run Without Debugging and Debug Mode (including VSCodium + `netcoredbg`), and provides an on-demand Launch Console Drawer.
